BOHO NEGOMBO WEBSITE CONCEPT
===========================

Files:
- index.html: main website
- styles.css: layout, responsive design and styling
- script.js: menu filters, shopping basket and WhatsApp order message
- assets/: photos extracted from your uploaded PDF and upscaled for high-resolution display

HOW TO OPEN:
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to open it in Firefox, Chrome or another browser.
4. Internet is needed for the Google Maps embed, Google Fonts and WhatsApp links.

ORDER FLOW:
Choose menu items -> Add to basket -> Enter your name and contact number -> Send order via WhatsApp.
WhatsApp opens with a pre-filled message to BOHO (+94 76 378 5873). The restaurant must reply to confirm the order.

IMPORTANT:
- This is an unofficial website concept, not an official BOHO website.
- Menu prices are based on publicly available menu listings and can change. Confirm current prices with the restaurant.
- Google rating shown is a reported public listing value (4.6/5) and can change. The review button opens Google Maps; this page does not invent customer reviews.
- PDF photos were upscaled and lightly sharpened for display. Upscaling increases pixel dimensions but cannot recover detail absent from the original images.
- Static website only; no database or server is required.
